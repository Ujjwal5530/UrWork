# UrWork - On-Demand Trade Services App

## What it does:

The UrWork app connects users with a variety of trade service providers, including plumbers, painters, salons, spas, and more. Users can easily book appointments, view service provider profiles, and manage their bookings within the app.

## What it is:

An Android mobile application developed using Kotlin.

## Technologies Used:

* **[Kotlin:](https://kotlinlang.org/)** Primary programming language.
* **[Firebase Firestore:](https://firebase.google.com/docs/firestore)** Cloud database for storing user data, service provider information, and bookings.
* **[Firebase Authentication:](https://firebase.google.com/docs/auth)** For user authentication and authorization.
* **[Firebase Database:](https://firebase.google.com/docs/database)** For real-time data synchronization. 
* **[Fragments:](https://developer.android.com/guide/fragments)** For managing different sections of the app (e.g., home, profile, booking).
* **[MVVM Architecture:](https://learn.microsoft.com/en-us/dotnet/architecture/maui/mvvm)** For clean code separation and improved testability. 

## Ambition:

The ambition of this project is to develop a functional and user-friendly platform that connects users with reliable trade service providers, simplifying the process of booking appointments and improving access to local services.

## Current Stage:

This project is currently **work in progress**. 

## Known Issues and Limitations:

* **Limited Functionality:** Currently, the app primarily focuses on user authentication and basic profile management. 
    * Features such as service provider browsing, appointment scheduling, payment integration, and in-app communication are still under development.
* **Data Limitations:** The app currently relies heavily on Firebase for data storage. 
    * Integrating with other services or implementing more robust data management strategies may be necessary for scalability and performance. 

This README provides a brief overview of the UrWork app. I am continuously working on expanding the app's features and improving its overall functionality.
